HyDE 的核心概念

口語問句和法條之間有「詞彙 gap」，把問句先讓 LLM 翻譯成假設的法條語言，再用這段假設條文做 embedding 搜尋，可以縮短這個 gap。

三種 HyDE Prompt

Prompt A（嚴格格式）

限制 50-100 字、第X條格式。資訊量被壓縮，R@10 最低。

Prompt B（放鬆格式）★

長度不限，可含條號、釋字、法律原則。比 A 高 +0.153 R@10（p≈0）。

Prompt C（三角度）★

同時生成條文、釋字、原則三種視角的假設文字。比 A 高 +0.157 R@10（p≈0）。

SECTION 6b

Exp-A 結論：三個關鍵發現

結論一：HyDE 在每一條路上都有效

不管底層是 BM25、Dense 還是 Hybrid，加了 HyDE 之後 R@10 全部顯著提升。BM25 受益最大（+73.2%），因為口語問句和法條的詞彙 gap 最大，HyDE 直接填平這個 gap。

圖 10：各路徑加入 HyDE 前後的 R@10 對比。綠色箭頭=HyDE 帶來的提升，百分比標注相對改善幅度。紅虛線=論文 best 0.472。
升級路徑Before（no HyDE）After（HyDE Prompt A）+Delta相對改善p

Hybrid（no rerank）：R3 → R90.3170.407+0.090+28.4%—

💡
為什麼 BM25 受益最大？ BM25 純靠詞彙精確匹配。原始問句「個人可否在家教網站找外籍教師？」幾乎沒有「工作許可」「居留」等法律術語。HyDE 生成的假設條文直接補上這些詞彙，BM25 就能命中。Dense embedding 本來就能處理語意近似，所以 HyDE 的加成相對較小。

結論二：Reranker 需要 Hybrid 候選池才有效

同樣是加 Reranker，Dense-only 候選池帶來的提升只有 Hybrid 候選池的一半左右。候選池越多樣，Reranker 越能發揮精篩功能。

圖 11：左=Rerank 前後 R@10 對比；右=Rerank 帶來的 Delta。紫色=Dense 候選池，藍色=Hybrid 候選池。Hybrid 的提升量約為 Dense 的 2 倍。

為什麼 Dense-only 候選池讓 Reranker 效果差？ text-embedding-3-small 對「概念相近但條號不同」的法條給出非常接近的相似度，導致 Dense top-50 候選池同質性過高。Reranker 面對一堆「都很像」的候選時，能精篩的空間有限。BM25 加入後帶來詞彙維度的多樣性，候選池更豐富，Reranker 才能真正從中挑出最好的。

結論三：Prompt 設計的影響——看在哪條路上

Prompt B/C（放鬆格式）在 Dense no-rerank 路上比 Prompt A 高出 +0.15 R@10；但在最優 pipeline（hybrid+rerank）上，B/C 反而略低於 A（約 -0.01），差異不顯著。

⚠️ 混雜因子：temperature 沒有控制
Prompt A 用 temperature=1.0（預設），B/C 用 temperature=0。Dense no-rerank 路上的 +0.15 改善，有多少來自 prompt 本身的改善，有多少來自 temperature=0 帶來的生成確定性，目前無法拆分。需要加入「Prompt A + temperature=0」的控制組（R19/R20 正在補做）才能確定。
🎯

Corpus Coverage 說明

⚠️ 先前報告中的「覆蓋率 23.4%」分析已撤回
原先分析（coverage_check.py）是用正規表達式在題目文字中搜尋法律名稱，沒搜到法律名就判定「法律不在 corpus」。
這個邏輯有根本性錯誤：律師考試題目（如刑法案例）完全不需要在題幹裡寫「刑法」二字，因此 75.8% 的題目文字沒有出現法律名稱，並不代表那些題考的法律不在 corpus 裡。實際上那些題考的大多是刑法、民法等核心法律，這些都在 production corpus 的 38 部法律之中。

正確的認識是：production corpus 的 38 部法律（刑法、民法、公司法、著作權法等）恰好涵蓋律師考試的主要考科，不存在大規模的 corpus coverage 缺口。Exp-B 準確率天花板低的真正原因尚未確定，需要進一步實驗（如單獨分析各法律的 retrieval hit rate）。

為什麼 BM25 在 Exp-B 強，在 Exp-A 卻墊底？

Exp-A（LFQA）Query 風格

「外國人需要申請工作許可嗎？」「個人可以找外籍教師嗎？」口語化，多種改寫，BM25 詞彙不匹配法條。

Exp-B（律師考題）Query 風格

「累犯之規定適用於過失犯嗎？」「瑕疵擔保請求權之消滅時效…」正式法律術語，BM25 幾近完美匹配。

Dense-only 候選池同質性過高（text-embedding-3-small 對概念相近的法條給出近似分數）。Reranker 在低多樣性池裡傾向 promote 表面文字最匹配的條文，律師考題常需多條法條交互（民法+釋字），反而遺漏了關鍵條文。

結論：Reranker 不是免費午餐。
Dense-only 候選池同質性高 → Reranker 放大偏誤 → 答題退步。
Hybrid 候選池（BM25 提供詞彙互補）→ Reranker 正常發揮 → 大幅提升。
建議：只在 hybrid 或多源候選池上使用 reranker。

診斷二：aug_reranker 完全崩潰（-55.1% R@10）

實驗設計：把 HyDE 生成的假設條文一起拼入 reranker 的 query（希望 reranker 也受益於 HyDE）。結果完全反效果。

圖 9：R7（orig query rerank）vs R12（aug query rerank）。R@10 從 0.546 崩到 0.245（-0.301），zero_recall 從 23.5% 跳到 55.3%。
aug_reranker 的問題

aug_query = orig_query (~29 tokens) + 假設條文 (~270 tokens) = ~299 tokens。Cross-encoder 兩邊都是「法條語言」，50 個候選法條的分數全部偏高且互相接近，reranker 失去區分能力，排序退化為近似隨機。

HyDE 信號的邊界

Embedding 層：成立（+26.6%）— 假設條文把 query 拉近法條空間。
Cross-encoder 層：失效（-55.1%）— 兩邊都是法條，所有候選分數趨同，分辨力消失。

SECTION 11

誠實的限制與不足

已知混雜因子

[已解決] Prompt B/C 同時改了 temperature（1.0 → 0）
R19/R20 控制組已確認：temperature 效果可忽略（Δ<0.003）。Prompt B/C 在控制住 pipeline 後比 A 差 -0.01~-0.014（NS）。舊報告的 +0.153 完全來自 pipeline 差異（dense→hybrid, no_rerank→rerank）。
[高度] Exp-A 結論不能直接推廣到 Exp-B
兩個 corpus 設計完全不同（22,728 條 vs 8,470 條），Spearman rho ≈ 0 已說明這件事。Exp-A 的方法排名對 Exp-B 毫無預測力。
[中度] Exp-B 準確率天花板的真正原因尚未確定
先前報告中「76.6% 題目法律不在 corpus」的說法已撤回（方法論錯誤：以題幹是否出現法律名作為 coverage 指標）。Production corpus 的 38 部法律涵蓋律師考試主要考科。真正的瓶頸可能是多法條推理、題目難度或 retrieval precision 不足，需要進一步實驗驗證。

設計不足

[中度] LawFactsQA-TW 題目分佈偏就業服務法
大量 query 涉及外籍人士工作許可，不代表一般民眾法律諮詢的分佈。結論在「外籍就業法規」以外領域的泛化性需要謹慎。
[中度] Dense embedding 未用 domain-specific 模型
論文用 BGE-m3（繁中法律語料預訓練），本實驗用 text-embedding-3-small（通用）。這導致 Dense 在 Exp-A 落後論文 -13.6%。使用 BGE-m3 可能改變整體排名。
[低度] aug_reranker 崩潰機制無 raw score 直接驗證
機制是從 R@10/R@50 行為比率推論（44% vs 78%），說服力足夠，但未記錄 cross-encoder 的實際分數分布。
